# Security Policy

PromptDock stores prompts locally in the user's Application Support directory.

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub security advisory if available, or by contacting the maintainer through the repository owner profile.

Avoid posting exploit details in public issues until the issue has been reviewed.

## Scope

Relevant issues include:

- unintended prompt data exposure
- unsafe file import behavior
- clipboard handling bugs
- insecure persistence or sync behavior
