Why this deserves to exist.

The winning product is not just a snippet manager. It is a prompt operating layer: fast enough for menu bar use, structured enough for teams, and plain enough that non-technical users trust it.

Prompt reuse is workflow memory

Repeated prompts encode how a person likes work to be framed. Losing them in random notes files makes every agent session start from scratch.

The menu bar is the right surface

Prompts are needed while someone is already inside Terminal, Codex, Claude Code, Slack, Jira, or a browser. A full app should be optional.

Variables beat static snippets

Useful prompts usually have slots: repo name, audience, severity, client tone, incident ID, output format. Fillable prompts make reuse precise.

Teams need governance

IT and consulting teams need shared prompt libraries, approved wording, redaction reminders, ownership, and review dates.

Primary users and jobs.

The same core product works across roles because the common job is controlled repetition: use the right prompt, with the right context, in the right tone.

Software engineer

Lives in editor, terminal, GitHub, and AI coding agents.

  • Paste code review prompts into Codex or Claude Code.
  • Keep repo-specific conventions and test commands.
  • Turn bug notes into reproduction prompts.

IT and SRE operator

Handles tickets, incidents, logs, access requests, and compliance language.

  • Summarize incidents from notes and logs.
  • Generate user-facing outage updates.
  • Apply approved security phrasing.

Management consultant

Reuses analysis frames, meeting follow-ups, executive summaries, and client tone.

  • Convert raw notes to slide-ready synthesis.
  • Adapt wording by client and seniority.
  • Maintain reusable discovery questions.

Key interaction

Keyboard-first search, recent prompts, pinning, and quick paste. The menu bar app should not require people to manage libraries during flow; it should only help them retrieve and fill.

Why it matters

Variables let one prompt serve many contexts without duplicating near-identical copies. This becomes critical for consultants and IT teams who reuse patterns with different clients, systems, and policies.

Starter prompt patterns.

The product can ship with editable examples, but the strongest value is importing the user’s existing Sublime Text prompts and turning them into structured templates.

Engineer Act as a senior engineer reviewing {{change_summary}}. Prioritize correctness, data loss, security, and tests. Return only actionable findings.
IT operator Summarize this incident for {{audience}}. Include timeline, impact, current status, owner, and next update time. Avoid speculation.
Consultant Turn these notes into an executive-ready update. Use {{client_tone}} tone. Separate decisions, risks, asks, and next steps.

Recommended product shape.

Start narrow: local-first prompt library, menu bar retrieval, variables, and import. Add team and AI-agent integrations after the core habit is proven.

MVP

Personal prompt library

  • Add, edit, delete, duplicate, tag, favorite.
  • Menu bar search with copy and paste actions.
  • Variables with remembered defaults.
  • Import from plain text, Markdown, and folders.
  • Local encrypted storage and iCloud sync option.

Power features

  • Prompt health: unused, duplicate, missing variables.
  • App-specific suggestions for Terminal, Slack, browser, Jira.
  • Context packs for repo rules, client style, and policies.
  • Shared team libraries with approvals and review dates.
  • One-click handoff to Codex, Claude Code, ChatGPT, and clipboard.

Positioning thought: the product should avoid being “another notes app.” The sharper promise is: keep your proven AI instructions one keystroke away, fill them correctly, and reuse them without breaking focus.
