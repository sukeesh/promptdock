# Contributing

Thanks for considering a contribution to PromptDock.

## Development

Build the app:

```sh
swift build
```

Run the app:

```sh
swift run PromptDock
```

## Guidelines

- Keep the app native, fast, and memory-light.
- Avoid adding dependencies unless they clearly improve the product.
- Prefer local-first behavior and explicit user control.
- Keep UI changes readable in light and dark macOS environments.
- Run `swift build` before opening a pull request.

## Pull Requests

Please include:

- a short description of the change
- screenshots or screen recordings for UI changes
- notes about any performance or storage impact
